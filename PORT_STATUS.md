### Known lifecycle gaps (explicit, tracked)
- Usage-stats report `memstats` / `num_goroutine` are Go-runtime values; mimir-rs reports RSS/VSZ-based memory figures, zero GC fields and the number of live tokio tasks.
- Panics in gRPC/HTTP request handlers are isolated to the request (tokio/hyper); in Go a panicking gRPC handler crashes the process (net/http and httpgrpc handlers recover in Go too). Panics in ingester background loops fail the ingester like any subservice failure (graceful stop, exit 1).
